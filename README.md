# Student Management System

## 📌 Project Description

The Student Management System is a Java-based application developed to manage student information efficiently. It allows users to add, view, update, delete, and manage student details using a simple and user-friendly system.

## 🛠️ Technologies Used

* Java
* JDBC
* MySQL
* Maven
* HTML
* CSS
* JavaScript
* Bootstrap
* Eclipse IDE

## ✨ Features

* Add new student details
* View student details
* Update student information
* Delete student records
* Search and manage student records
* Store student information in MySQL database

## 🏗️ Project Architecture

The project follows a layered architecture:

* **Model** – Represents student data
* **Controller** – Handles user input and application flow
* **Service** – Contains business logic
* **Repository** – Performs database operations using JDBC
* **Database** – MySQL database for storing student records

## 🗄️ Database

**Database:** MySQL

### Student Table

| Field      | Description          |
| ---------- | -------------------- |
| ID         | Unique student ID    |
| Name       | Student name         |
| Email      | Student email        |
| Department | Student department   |
| Phone      | Student phone number |

## ▶️ How to Run the Project

1. Install Java JDK.
2. Install Eclipse IDE.
3. Install MySQL and MySQL Workbench.
4. Create the `student_management` database in MySQL.
5. Create the required student table.
6. Open the project in Eclipse.
7. Update the MySQL database connection details in the project.
8. Make sure Maven dependencies are downloaded successfully.
9. Run the Java application from Eclipse.
10. Use the application to manage student records.
